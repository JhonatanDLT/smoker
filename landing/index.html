Synthetic Postgres data that ships with proof.

pgproof reads your schema, generates rows, and verifies every constraint it can find. The output is a report you can hand to a reviewer or an auditor — including what it could not verify.

Your staging data passes tests because nobody checks the constraints.

Copying production is a legal risk. Faker-style seeds produce plausible values that break foreign keys, sums and enum domains — the failure shows up as a flaky test or a demo that dies on stage.

pgproof treats the schema as the specification. It reads pg_catalog, turns constraints into invariants, generates rows that satisfy them, and then proves it.

It reads your schema. You do not describe it twice.

Generation is deterministic and the report carries a SHA-256 of the dataset. Commit the plan, pin the version, and let CI fail when an invariant breaks.

Install

pipx install pgproof

export PGPROOF_SOURCE_DSN=postgresql:///myapp
export PGPROOF_TARGET_DSN=postgresql:///myapp_test

pgproof run --rows 5000 --seed 42 --spec plan.yml --out proof

Requires Python 3.11+ and PostgreSQL 14–17. Runs fully offline.
